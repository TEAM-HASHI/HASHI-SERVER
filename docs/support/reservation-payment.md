# 예약 입금 대기 배포와 기존 예약 처리

V46은 기존 예약에 입금 기한을 채우지 않는다. 마이그레이션을 먼저 적용하고 모든 서버 인스턴스를 새 버전으로 교체한다. 고객 앱과 어드민이 새 상태를 표시할 수 있을 때 어드민에서 입금 대기를 사용한다.

이전 버전에서는 관리자가 취소한 예약을 신청·연락 단계로 되돌려도 결제 상태가 CANCELED로 남았다. 배포 전에 아래 읽기 전용 쿼리로 해당 건수를 확인한다.

```sql
SELECT COUNT(*) AS reopened_canceled_bookings
FROM reservation
WHERE reservation_status IN ('REQUESTED', 'CONTACTING')
  AND payment_status = 'CANCELED';
```

이런 예약으로 다시 진행해야 한다면 어드민에서 기존 건을 취소하고 회원에게 새 예약을 접수하도록 안내한다. 기존 건의 결제는 이미 취소 상태이므로 서버는 포인트 원장을 변경하지 않는다. 원복 여부에 대한 문의는 원래 예약의 포인트 사용·복원 내역을 확인해 처리한다.

방문 완료를 잘못 표시한 결제 완료 건은 확정 또는 연락 중으로 정정할 수 있다. 결제 상태는 PAID로 유지된다. 입금 대기를 다시 시작할 수 없고, 정정한 예약을 취소해도 확정 후 취소에 해당해 사용 포인트는 복원되지 않는다.
